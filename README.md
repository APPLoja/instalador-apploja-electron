# Instalador APPLoja Electron

Instaladores Windows (x64) do APPLoja, ERP/PDV desktop offline-first.

Baixe a versão mais recente em [Releases](https://github.com/APPLoja/instalador-apploja-electron/releases/latest).

> O instalador ainda não tem assinatura digital: o Windows SmartScreen pode exibir um aviso; use "Mais informações" > "Executar assim mesmo".
